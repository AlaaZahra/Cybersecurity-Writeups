\# Web Security Challenges



This directory contains web application security challenges completed on CyberTalents.



The focus is on understanding how web vulnerabilities work rather than simply retrieving the flag.



\---



\## Topics Covered



\- Information Disclosure

\- Sensitive Data Exposure

\- SQL Injection

\- Cross-Site Scripting (XSS)

\- Path Traversal

\- Authentication

\- Access Control

\- Server Misconfiguration
